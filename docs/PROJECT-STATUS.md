# Project status and v0.1 review

Updated 9 November 2026. This is the current acceptance record, with earlier evidence identified by scope. Game chapters retain the detailed routine explanations and fixtures. An implementation, a passing route and a release-ready game are different milestones.

## Current position

**ROM → TypeScript → Web** is the agreed direction. ROM Studio recovers understandable game code; MAMEKIT explains machine behavior from MAME source. The owner declined the RetroRecomp Emscripten/WebAssembly prototype. [Inspiration](INSPIRATION.md) credits Contra, RetroRecomp, arcade-decomp, TMNT, MAMEKIT and related projects, with proposed lessons distinguished from implemented capabilities.

**On 9 November 2026 the owner adopted two execution tiers and narrowed the hard rule to no Emscripten.** The reference tier remains the exact, verified path behind Learn and ROM Desk and may run slower. A play tier may implement system work beneath the game at a higher level, such as recognized N64 microcode, GPU drawing or WebAssembly, to reach full speed. It must keep the recovered game code and pass comparisons against the reference tier. [RELEASES.md](RELEASES.md#execution-tiers--decided-9-november-2026) records the decision and its implications; [Architecture](ARCHITECTURE.md#execution-tiers) defines the boundary. The first SM64 play tier implements Fast3D graphics tasks at a high level and draws in a parallel RDP worker. With compiled CPU blocks and real-time pacing, the castle fixture runs at full PAL speed (25 FPS) in Chrome, against 7.3 on the reference tier; the title screen still reaches only about 18 FPS. Frames differ from the reference tier on about 1.7% of pixels, mostly triangle edges. See [performance](../src/games/n64/sm64/docs/PERFORMANCE.md#play-tier-first-implementation-9-november). It has not been packaged or accepted.

**The release requires six excellent games—Lemmings, Nebulus, Elite, Super Mario Bros., Tetris and Super Mario 64—plus the ROM Desk workbench. On 9 November 2026 the owner accepted all six games as working; their packages are `release-ready` and offer Play Game.** Documented limits for each game remain below and in its README. ROM Desk is not implemented yet, so v0.1 is not complete.

## Mario music tempo check

## Source hygiene, outputs and release automation

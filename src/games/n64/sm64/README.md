# Super Mario 64

The sixth v0.1 target is the European revision-0 Nintendo 64 release, cartridge code **NSMP**. The supplied 8 MiB image lives in `roms/n64/sm64/`. It is byte-swapped within each 16-bit word. ROM Studio preserves that input and normalizes a copy for big-endian reads.

[Recipe](recipe.json) · [Startup](docs/STARTUP.md) · [CPU and machine](docs/CPU.md) · [Audio microcode](docs/AUDIO.md) · [Graphics](docs/GRAPHICS.md) · [Performance](docs/PERFORMANCE.md) · [N64 backend](../../../../docs/systems/n64/README.md)

The raw SHA-256 is pinned by the recipe. Its normalized SHA-1 matches the European release recorded by [n64decomp/sm64](https://github.com/n64decomp/sm64/blob/master/sm64.eu.sha1). That project is a reference for recovered names and structures, separate from ROM Studio's implementation.

Identification, byte-order handling and functional CPU/RSP/device backends are implemented. Bounded startup, audio, clear, texture and rendered-task studies have static replay evidence. Later execution reaches Mario's title, the original menus and Peach's opening scene. A captured title-to-opening route also completed fresh static CPU/RSP replay for its recorded source fingerprint. This is separate from current browser acceptance. Images have visible raster/lighting artifacts and the machine clock is functional rather than hardware-verified.

The checked local software package reaches the original menus, opening sequence and Mario outside the castle. Movement, jumping, an airborne kick, a grounded punch and pause/resume have been checked. A later hillside profile measured 4.75 completed graphics tasks per second, still below playable acceptance; sound, saves, rendering and ordinary progression remain unfinished. **SM64 is not release-ready.** NES sound has completed bounded acceptance; current work targets faster translated CPU/RSP execution while preserving original state and device ordering. See [current status](../../../../docs/PROJECT-STATUS.md) and [performance evidence](docs/PERFORMANCE.md) for each run's scope.

Run `npm run cli -- boot --title sm64` to generate and verify the bounded CPU and RSP audio studies. Their source package is under `dist/work/games/n64/sm64/analysis/startup/source-study/`, separate from the browser package. `npm run dev` offers its chapters under `/n64/sm64/learn`; assembly views require an assembled package containing those sources. Use `npm run cli -- boot --title sm64 --until frame` for the first rendered task and `dist/work/games/n64/sm64/analysis/render/first-frame.png`. Its 16 nonblack pixels are the tiny beginning of the logo animation. The shorter `--until graphics` and `--until textures` stages retain the clear-task and texture/vertex studies. These studies do not satisfy the six-game v0.1 gate.
